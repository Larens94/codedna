Privacy Policy

Last updated: August 2026  ·  CodeDNA CLI and integrations

CodeDNA itself collects no telemetry or personal data. Structural analysis stays local. Optional AI-powered annotation sends selected source context only to the model provider you configure.

1. Overview

CodeDNA is an open-source CLI and integration layer that annotates source files with architectural metadata. The CodeDNA project operates no collection server and receives no source code, project metadata, or usage telemetry.

2. Data we do not collect

  • Source code or file contents
  • Project structure or file paths
  • Personal information of any kind
  • Usage statistics, telemetry, or analytics
  • API keys or credentials

3. Local structural mode

Commands such as codedna init . --no-llm, check, verify, impact, and doctor analyze local files without sending them to a CodeDNA service.

4. Optional model providers

If you explicitly run AI-powered annotation with --model, CodeDNA sends the source context required to generate semantic rules: to the provider selected by that model configuration. That processing is governed by the provider's terms and privacy policy. Local Ollama models can be used when no external model service is desired.

5. Coding-agent integrations

Claude Code, Codex, OpenCode, Cursor, Copilot, Cline, Windsurf, Aider, and other agents process files according to their own configuration and privacy policies. CodeDNA instruction files and hooks do not add telemetry, but they do not replace the privacy terms of the underlying coding agent.

6. Third-party services

CodeDNA includes no analytics, crash reporting, advertising, or tracking libraries. Network access occurs only when you request an installation download or configure an external model provider or coding agent.

7. Changes to this policy

If this policy is updated, the revised version will be published at this URL with an updated date at the top. No material changes are anticipated given the local-only nature of the plugin.
