Portabilità03 / 14

Il protocollo

Quattro livelli, come uno zoom.

LIVELLO 0

.codedna

Mappa del progetto: pacchetti, dipendenze, file chiave. Si legge prima di aprire il codice.

LIVELLO 1

Header del modulo

exports, used_by, related, rules, message. Poche decine di token, in cima al file.

LIVELLO 2

Rules sulla funzione

Il vincolo sta sulla funzione che lo deve rispettare, non in un documento a parte.

LIVELLO 3

# Rules inline

Una riga sopra la logica non ovvia: un if, un ordine di operazioni, un caso limite.

Quattro livelli04 / 14

Esempio a video

Un file basta per orientarsi.

"""revenue.py — Ricavi mensili.

exports: monthly_revenue(year, month) -> dict
used_by: api/reports.py → revenue_route
        api/serializers.py → Schema [cascade]
related: billing/currency.py — multi-valuta
wiki:    docs/wiki/revenue.md
rules:   get_invoices() ritorna TUTTI i tenant
        filtrare is_suspended() PRIMA della somma
message: arrotondamento multi-valuta
"""

used_by — due file dipendono da questo. Uno è cascade: se cambio il contratto, va aggiornato.

rules — il filtro sui tenant sospesi va applicato prima della somma. C non può più saltarlo.

wiki — la pagina esiste. L’agente sa che l’header non gli basta.

Esempio05 / 14

I campi non sono sinonimi

Quattro domande, quattro risposte.

used_by:

Chi importa questo file. È il grafo inverso: l’agente lo segue invece di cercare in tutto il repository.

related:

Chi fa la stessa cosa senza importarmi. Il bug trasversale, senza una catena di import.

rules:

Il meccanismo, non la soluzione. «La conversione timezone avviene prima», non «modifica questi tre file».

message:

Nota per l’agente successivo. Se la conferma, diventa una rules. Se non torna, la scarta con un motivo.

Provarlo

Tre comandi, in locale.

pipx install git+https://github.com/Larens94/codedna.git
codedna install --path . --tools codex --no-wiki-sync
codedna init . --no-llm

1 · CLI

Python 3.11+. Installazione isolata, senza toccare l’ambiente globale.

2 · Strumento

Al posto di codex: claude, cursor, copilot, aider e gli altri della tabella.

3 · Annota

Pass strutturale gratuito: exports e used_by. Le rules semantiche sono un passo dopo, con un modello.

Come leggere i numeri

Quattro limiti, detti subito.

  • Gemini 2.5 Pro guadagna meno e il risultato non è significativo (p=0,11).
  • Il 5/5 di related: è un caso, il bug unicode. Non è la media del benchmark.
  • Il 7/7 del #13495 è la qualità della patch. L’F1 di navigazione sullo stesso bug, con altri modelli, non racconta la stessa storia.
  • Sono risultati riportati dal progetto. Le run grezze non sono nel repository.
