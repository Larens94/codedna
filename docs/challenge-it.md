# CodeDNA Challenge — €200 (IT)

Versione sintetica. Regolamento completo (EN): [`challenge.md`](challenge.md) · Scaletta video: [`challenge-video-script.md`](challenge-video-script.md)

## In sintesi

- Premio **€200**, durata **1 mese**
- Minimo **5 submission valide** per sbloccare il premio
- Lavori sul **tuo** progetto (non i benchmark storici)
- Almeno **10 task** (facili / medi / difficili)
- Confronto **senza CodeDNA** vs **con CodeDNA**
- PR pubblica con metriche (anche a sfavore di CodeDNA)
- I bug si segnalano e si correggono upstream

## Livelli (regola d’oro)

| Livello | Esempi | Regola |
|---|---|---|
| **L0** | CodeDNA in-source | Layer sotto test |
| **L1** | Wiki LLM, skill, instruction pack | Se il Control lo ha, ce l’ha anche CodeDNA |
| **L2** | Graphify / graph memory | Stessa parity |

Se vuoi testare se **solo CodeDNA** sostituisce L1/L2, lo **dichiari** nei test. Stack diseguali non dichiarati = submission non valida.

## Come partire

1. Issue di iscrizione: template **CodeDNA Challenge entry**
2. Annota il progetto con CodeDNA
3. Congela i ≥10 task
4. Esegui Control vs CodeDNA a stack pari
5. Apri PR `challenge/<handle>/` + checklist in [`../challenge/SUBMISSION_TEMPLATE.md`](../challenge/SUBMISSION_TEMPLATE.md)

Date ufficiali di start/end: da compilare in [`challenge.md`](challenge.md) al momento della pubblicazione.
